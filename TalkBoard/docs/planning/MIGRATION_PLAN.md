## 🔧 기술적 고려사항

### 데이터 마이그레이션
- 기존 `Memorial` 데이터는 `memoryType: memorial`로 자동 설정
- 사용자가 추후 타입 변경 가능
- 기존 기능 (추모금, 기도 등)은 추모 타입에서만 활성화

### 하위 호환성
- 기존 API 및 데이터 구조 유지
- 점진적 마이그레이션으로 기존 사용자 영향 최소화
- 기존 기능은 모두 유지하면서 새 기능 추가

### 성능 최적화
- 타입별 인덱싱 추가
- 타입별 쿼리 최적화
- 캐싱 전략 수립
