# 🎯 새로운 앱 방향성: "추억의 정원"

## 📖 방향 전환 배경

기존 "기억의 정원" (디지털 추모관 앱)에서 **"추억의 정원"** (추억 저장소/기록 앱)으로 확장하여 더 넓은 시장을 타겟합니다.

### 전환 이유
1. **시장 확대**: 추모는 니치 마켓, 추억 기록은 대중적 니즈
2. **사용 빈도 증가**: 추모는 가끔, 추억 기록은 자주 사용
3. **수익 모델 다양화**: 더 많은 사용자 = 더 많은 수익 기회
4. **기존 코드 활용**: 추모 기능은 그대로 유지하면서 확장

---

## 🎯 새로운 핵심 가치

### 핵심 가치 제안
> **소중한 순간을 기록하고, 사랑하는 사람들과 함께 나누는 추억 저장소**

### 타겟 사용자 (확장)

#### 1차 타겟: 가족 중심 사용자
- **가족 추억 기록**: 생일, 결혼기념일, 여행, 일상 순간
- **가족 간 공유**: 멀리 있는 가족과 추억 공유
- **세대 간 연결**: 할머니/할아버지와 손자/손녀의 추억 공유

#### 2차 타겟: 커플/친구
- **데이트 기록**: 첫 만남, 기념일, 특별한 순간
- **우정 기록**: 친구들과의 추억, 모임, 여행
- **성장 기록**: 개인적인 성장 과정, 목표 달성

#### 3차 타겟: 추모 (기존 타겟)
- **고인 추모**: 사랑하는 사람을 기억하는 공간
- **반려동물 추모**: 함께했던 반려동물 추억

## 🌟 핵심 차별점

### 1. 다양한 추억 타입 지원
- **생일/기념일**: 생일, 결혼기념일, 첫 만남 등
- **여행**: 여행 사진, 동영상, 일기
- **일상**: 평범하지만 소중한 일상 순간
- **성장**: 개인적인 성장 과정, 목표 달성
- **추모**: 고인을 기억하는 공간 (기존 기능)

### 2. 감성적 UI/UX
- **따뜻한 톤**: 베이지, 크림, 파스텔 색상
- **여백 많은 레이아웃**: 감성적이고 편안한 느낌
- **타임라인 뷰**: 시간순으로 추억 탐색

### 3. 공유 및 커뮤니티
- **가족/친구 초대**: 선택적 공유
- **댓글 및 반응**: 추억에 대한 응원과 공감
- **공개 추억**: 다른 사람들과 공유 (선택적)

### 4. 프리미엄 기능
- **무제한 저장**: 사진, 동영상 무제한 업로드
- **고화질 저장**: 원본 품질 유지
- **커스텀 테마**: 다양한 배경과 테마
- **백업 및 내보내기**: PDF, 동영상 등으로 내보내기

## 📱 주요 기능 (확장)

### 1. 추억 저장소 생성
- **타입 선택**: 생일/기념일, 여행, 일상, 성장, 추모
- **기본 정보**: 제목, 날짜, 설명
- **미디어**: 사진, 동영상 업로드
- **일기/편지**: 텍스트 또는 음성으로 기록
- **공개 설정**: 비공개, 가족/친구만, 공개

### 2. 추억 탐색
- **타임라인**: 시간순으로 모든 추억 탐색
- **카테고리별**: 타입별로 필터링
- **검색**: 제목, 설명, 태그로 검색
- **기념일 알림**: 다가오는 기념일 알림

### 3. 공유 및 커뮤니티
- **초대**: 가족/친구 초대하여 함께 기록
- **댓글**: 추억에 대한 댓글 작성
- **반응**: 좋아요, 공감 등
- **공개 추억 탐색**: 다른 사람들의 공개 추억 둘러보기

### 4. 프리미엄 기능
- **무제한 저장**: 사진/동영상 무제한
- **고화질 저장**: 원본 품질 유지
- **커스텀 테마**: 다양한 배경과 테마
- **백업 및 내보내기**: PDF, 동영상 등
- **광고 제거**

## 🚀 마이그레이션 전략

### Phase 1: 기존 기능 유지 + 새 기능 추가 (1-2주)
- 추모 기능은 그대로 유지
- 새로운 추억 타입 추가 (생일, 여행, 일상 등)
- UI 텍스트 업데이트

### Phase 2: 데이터 모델 확장 (1주)
- 추모관 → 추억 저장소로 모델 확장
- 타입 필드 추가
- 기존 데이터 마이그레이션

### Phase 3: 새 기능 개발 (2-3주)
- 추억북 제작 기능
- 동영상 자동 생성 기능
- 공유 기능 강화

### Phase 4: 마케팅 및 출시 (1주)
- 새로운 브랜딩으로 마케팅
- 앱스토어 설명 업데이트
- 소셜 미디어 캠페인

## 📊 예상 효과

### 시장 확대
- **기존**: 추모 니즈 사용자 (매우 제한적)
- **신규**: 모든 사람 (가족, 커플, 친구, 개인)

### 사용 빈도 증가
- **기존**: 가끔 (기념일, 추모일)

### 수익 기회 증가
- **기존**: 프리미엄 구독, 추모금 수수료
- **신규**: 프리미엄 구독 + 추억북 제작 + 동영상 제작
